# 设备任务

本页面用于显示和管理所有下发到设备的任务，目前支持作业类型包括：入库、拣货、移库、补货、盘点。

![1735118963904-fc684d78-8a5d-4335-8806-21720e428d08.png](./img/ZPRsF41NAuEbm_uu/1735118963904-fc684d78-8a5d-4335-8806-21720e428d08-080666.png)

其中：

1. 任务状态为【作业中】，表示任务下发成功，等待设备回传，允许手动关闭任务（关联权限）。
2. 任务状态为【下发失败】，表示任务下发失败，需要手动重试，允许手动关闭任务（关联权限）。
3. 任务状态为【已完成】，表示任务回传成功，任务完结。
4. 任务状态为【已关闭】，表示任务已经关闭。
5. 点击关联系统单号，可以跳转到对应页面查看单据。
