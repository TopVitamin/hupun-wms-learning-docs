# 绩效策略

<font style="color:#374051;">绩效策略是用户可以根据自己的需求来设定积分计算规则，可细分到不同模块、不同环节、不同货主、不同操作员等条件。</font>

<font style="color:#374051;">绩效策略分类两类：普通绩效策略和例外累加规则。</font>

<font style="color:#374051;">具体页面如下：</font>

<font style="color:#374051;">基础绩效策略有优先级，最多只能匹配一个，优先级1最大，往后依次递减。同优先级时按策略编码从小到大匹配。</font>

<font style="color:#374051;">2.例外累加规则无优先级，支持匹配多个，有多个匹配时累加，并与基础绩效策略合计。详细的绩效策略介绍，请看【</font>[<font style="color:#448EE1;">基础绩效策略</font>](https://hupun.yuque.com/unzko7/lsbfg0/dx7fs2lnqq24mnz1)<font style="color:#374051;">】及【</font>[<font style="color:#448EE1;">例外累加规则</font>](https://hupun.yuque.com/unzko7/lsbfg0/tf8nvibl37hxc42g)<font style="color:#374051;">】</font>
