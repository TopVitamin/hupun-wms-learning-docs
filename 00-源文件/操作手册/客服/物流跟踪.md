# 物流跟踪

背景：3PL云仓业务场景下，提供给有物流属性的企业，服务货主订单物流服务质量及跟踪处理。

订单出库后，系统将自动订阅运单数据显示在物流跟踪内，方便查看后续订单物流轨迹情况以及预警订单流转进行处理。

![1705894434043-e07533f4-6cc3-4f3e-ab69-d3ffa66e9e92.png](./img/VW9G1GSyRi1niaWT/1705894434043-e07533f4-6cc3-4f3e-ab69-d3ffa66e9e92-834632.png)

该菜单联动仓库级自动订阅物流轨迹+操作员权限显示。

1.物流订单数据快捷看板：显示操作员有权限仓库对应各环节物流订单数据统计，物流状态、超时XXH、已超时均可携带时间自动查询对应订单数据。

2.支持出库、退货入库流程双向展示数据。

![1710488028240-42c5c454-028c-441e-a35a-f77673a02426.png](./img/VW9G1GSyRi1niaWT/1710488028240-42c5c454-028c-441e-a35a-f77673a02426-175911.png)

3.订单点击运单号可查看物流轨迹情况。

a.手填单号支持出库订阅和查看物流轨迹。

b.修改单号后可二次订阅。

4.订单根据对应环节配置超时预警时间计算是否超时，超时后自动标记，用户可在物流跟踪或异常订单-物流预警内查看并支持点击通知处理进行处理。（去除异常后对应去除异常数据）

5.失败记录点击跳转订阅失败订单页

a.可查看订阅失败订单数据并进行重新订阅操作。

b.支持取消订阅，取消后订单无订阅失败标记，订单不跟随业务配置预警。

![1705894963790-55c5d5ce-63e7-4a2e-a0d5-133b05f22e3b.png](./img/VW9G1GSyRi1niaWT/1705894963790-55c5d5ce-63e7-4a2e-a0d5-133b05f22e3b-360932.png)

6.原单入库、销退入库（前提：入库预约单上的承运商和运单号和原出库单一致）后，自动取消订阅。

7.单号来源：历史记录——回收的电子面单对应的记录；出库订单——出库的电子面单对应的记录。

8.记录自动清除时间：

+ 未揽收+超时已处理=7天
+ 揽收后至签收前+已处理=15天
+ 已签收/完结=15天
+ 任意节点超时未处理=最后轨迹更新时间2个月
