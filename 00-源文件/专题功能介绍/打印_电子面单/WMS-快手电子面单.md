# WMS-快手电子面单

业务背景：

应快手平台要求，近期将对用户订单数据逐步加密，数据加密后，商家必须切换快手官方提供的快手电子面单进行打单发货，不然无法解密打印面单，影响商家正常打单发货。

![1723444434229-15c4be9d-297d-4afb-8fca-b164290372f0.png](./img/p1YSxcr9V1lLcpwv/1723444434229-15c4be9d-297d-4afb-8fca-b164290372f0-865165.png)

一.店铺订购和保证金退款



店铺先订购WMS应用，[点击订购](https://fuwu.kwaixiaodian.com/new/detail?id=4313364561014)，选择电子面单订购专用版。



![1703126885319-e8a8eef7-07a2-4204-bf31-58a7bda2ad8f.png](./img/p1YSxcr9V1lLcpwv/1703126885319-e8a8eef7-07a2-4204-bf31-58a7bda2ad8f-829161.png)





订购成功后，在WMS系统里进行保证金退款，平台侧会收取0.6%的技术服务费，即付2000元，退款1988元，退款周期35天左右。



![1703126885710-d0fab427-cd2e-4502-ac50-b5e4374b2fa7.png](./img/p1YSxcr9V1lLcpwv/1703126885710-d0fab427-cd2e-4502-ac50-b5e4374b2fa7-437766.png)



![1703126886119-1f4073de-a367-49fb-9e26-6b060999ff1f.png](./img/p1YSxcr9V1lLcpwv/1703126886119-1f4073de-a367-49fb-9e26-6b060999ff1f-180905.png)



二. 店铺授权



选择已有的快手店铺，点击修改->打开店铺管理页面->点击授权，授权成功后->点击保存。



![1703126886626-131e5aea-5bd8-4f60-94b4-aa45d5372a4a.png](./img/p1YSxcr9V1lLcpwv/1703126886626-131e5aea-5bd8-4f60-94b4-aa45d5372a4a-233391.png)

 2.新增店铺->选择快手小店->点击授权，授权成功后->点击保存。

![1703126886932-25f392c4-eeaf-4da5-8368-c22fe1d28926.png](./img/p1YSxcr9V1lLcpwv/1703126886932-25f392c4-eeaf-4da5-8368-c22fe1d28926-293547.png)

![1703126887325-8c57957c-f169-485f-ba53-28818d659c19.png](./img/p1YSxcr9V1lLcpwv/1703126887325-8c57957c-f169-485f-ba53-28818d659c19-912702.png)

三. 承运商设置



承运商档案页面->点击新增，选择线上物流和快手模板，点击保存。



![1703126887632-90f552f3-e6e8-42bf-8861-7f413caf772f.png](./img/p1YSxcr9V1lLcpwv/1703126887632-90f552f3-e6e8-42bf-8861-7f413caf772f-596392.png)





点击开启电子面单->选择使用快手电子面单接口->选择店铺开启，设置网点和网点编码->点击保存。



![1703126888171-2f7ffdc7-ce91-4dd3-a74c-12430f0e2a29.png](./img/p1YSxcr9V1lLcpwv/1703126888171-2f7ffdc7-ce91-4dd3-a74c-12430f0e2a29-472358.png)





PS：顺丰速递需要快递服务里填写客户编码。



四.安装快手打印控件

[点击下载快手打印控件](https://s1-11586.kwimgs.com/kos/nlav11586/kuaishou-print-installer.exe" \o "点击下载快手打印控件" \t "/Users/liuyanhong/Documents\\x/_blank)，然后根据提示进行安装即可，安装成功双击打开。

五.面单申请



上游ERP/OMS推快手订单到WMS，在WMS里进行申请单号打单发货。
