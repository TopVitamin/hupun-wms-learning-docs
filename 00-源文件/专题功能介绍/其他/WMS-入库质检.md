# WMS-入库质检

### 名词解释
入库前质检（IQC, Incoming Quality Control）

### <font style="color:rgb(64, 64, 64);">背景</font>
<font style="color:rgb(64, 64, 64);">电商商品来源复杂，质量参差不齐。入库质检能防止残次品流入，减少退货差评，提升供应链效率，是保障用户体验的关键环节。</font>

### <font style="color:rgb(64, 64, 64);">意义</font>
+ 降低成本：从质量成本角度，预防成本远低于失败成本
+ 保证营销顺畅
+ 维护供应链稳定
+ 提供质量决策

### 适用行业
+ **母婴行业**:把控原材料及成品安全性美妆行业:验证成分合规、包装密封
+ **电器行业**:检测零部件性能、安全性
+ **奢侈品行业**:保障材质真伪、工艺精度
+ **医药行业:**遵循 GMP标准,检测原材料纯度
+ **服装行业**:检查面料质量、缝制工艺
+ **家具与大家居**:验证材质环保性、结构稳定
+ **印刷制品**:把控印刷色彩精度、文字清晰



### 普遍的痛点
+ 缺乏系统化质检记录

依赖纸质或碎片化记录,导致数据追溯困难、信息丢失,难以支撑质量分析与问题复盘。

+ 缺乏对供应商的持续监控

仅依赖入库时抽检,忽视供应商生产过程的质量波动,难以从源头预防质量风险,易导致批次性问题。

+ 缺乏对整体质量的量化评估

未建立统一的质量评估指标体系(如 PPM值、合格率趋势等),无法客观衡量效果及供应链整体质量水平



### 功能介绍
#### 功能开启依赖
使用入库质检功能前必需启用库存残次品管理![1751954996529-0d031a72-b1a4-4a78-8d6e-0137313df4ed.png](./img/Pp0EsAJ-SzM9JBrS/1751954996529-0d031a72-b1a4-4a78-8d6e-0137313df4ed-900918.png)

#### 入库流程控制
根据不同的入库预约业务决策是否进行质检

![1751957511262-7f813e0d-fe90-40a2-a9c2-4de9b2d7946a.png](./img/Pp0EsAJ-SzM9JBrS/1751957511262-7f813e0d-fe90-40a2-a9c2-4de9b2d7946a-256524.png)

点设置策略我们可以基于货主、业务单据以及单据中商品数量多寡来设置

![1751957576485-d8fdd1f5-1982-43ae-9286-35da1e5d5771.png](./img/Pp0EsAJ-SzM9JBrS/1751957576485-d8fdd1f5-1982-43ae-9286-35da1e5d5771-194203.png)

质检作业依赖于来源数量，在流程中启用质检时需同时启用清点环节

设置策略后如果入库预约单符合策略条件，则视为强制作业流程，即必须完成配置的作业环节

#### 质检任务
![1751958447275-ea696ad4-706f-434b-9941-7067e133e0be.png](./img/Pp0EsAJ-SzM9JBrS/1751958447275-ea696ad4-706f-434b-9941-7067e133e0be-037614.png)

##### 质检任务创建
质检任务即交由质检员操作的任务。任务中确定了要质检的商品及相应的检验数量



**任务创建的两种方式**

![1751959223463-e07348c2-b662-46cf-879f-eaa3724c8d0e.png](./img/Pp0EsAJ-SzM9JBrS/1751959223463-e07348c2-b662-46cf-879f-eaa3724c8d0e-448290.png)

+ **按入库任务创建**适合整单质检的场景，适合逐单逐环节作业
+ **按清点单创建** 适合商品多，分批作业

**强制环节任务的识别**

在创建任务时对于强制环节的任务会优先展示，任务单号会有锁定标记

![1751960148713-6f519392-00ca-4c04-b9ca-a92466b354e4.png](./img/Pp0EsAJ-SzM9JBrS/1751960148713-6f519392-00ca-4c04-b9ca-a92466b354e4-713977.png)



选择明细创建任务

在创建质检任务的时候，可以选定部分明细来创建

![1751959706525-6e63c13b-ca07-4e73-b3a7-815084457f97.png](./img/Pp0EsAJ-SzM9JBrS/1751959706525-6e63c13b-ca07-4e73-b3a7-815084457f97-367809.png)



##### 记录质检结果
点击任务上的质检按钮

通过添加正品/次品的方式在每个明细商品下记录质检结果，正品即质检通过的商品，次品即质检异常的商品

点击添加所有正品按钮后，所有明细自动添加一条正品明细并带出已检验数量，减少手工操作

![1765778733522-8dc371d4-3f9d-4134-95dd-b3d1b745728c.png](./img/Pp0EsAJ-SzM9JBrS/1765778733522-8dc371d4-3f9d-4134-95dd-b3d1b745728c-344932.png)

针对不同的质检次品，可以填写记录问题

![1751968461274-83c981f0-d893-47ec-a978-dd64bf09e816.png](./img/Pp0EsAJ-SzM9JBrS/1751968461274-83c981f0-d893-47ec-a978-dd64bf09e816-947000.png)

也可提前预设一些问题原因

![1751968517300-5ad63a72-6f11-4b1f-96f9-3cd6d06d41cf.png](./img/Pp0EsAJ-SzM9JBrS/1751968517300-5ad63a72-6f11-4b1f-96f9-3cd6d06d41cf-155043.png)

##### 上传质检凭证
对于一些特殊问题、质量缺陷等，也可以上传缺陷商品图片作为记录，每个质检任务可记录10张图片

![1751969790054-0e4dab35-c8be-45a1-b8ca-4119d343f6e0.png](./img/Pp0EsAJ-SzM9JBrS/1751969790054-0e4dab35-c8be-45a1-b8ca-4119d343f6e0-957342.png)

##### 质检任务暂存
对当天作业不完的质检任务，我们可以通过点击暂存来保存记录当日的数据

![1751960597815-303a22d8-7a55-408c-a00a-b09409c94ba8.png](./img/Pp0EsAJ-SzM9JBrS/1751960597815-303a22d8-7a55-408c-a00a-b09409c94ba8-609169.png)

##### 质检任务通过
在记录完质检数据后可根据结果决定是否通过质检，通过质检代表着该批货允许入库了，

质检通过后，将产生如下影响

+ 该任务完成数量可提交入库
+ 质检任务不在允许编辑
+ 生成质检单



#### 抽检
##### 抽检策略
抽检策略是按照单据类型、供应商等条件来配置的，如果没有配置抽检策略，则默认做全检

![1751970124233-27562a42-2981-4c41-abd6-1fc3be44cc14.png](./img/Pp0EsAJ-SzM9JBrS/1751970124233-27562a42-2981-4c41-abd6-1fc3be44cc14-577545.png)

抽检策略中根据不同的条件来设置比例

抽检比例在创建质检任务的时候参与计算 应检验数量

应检验数量在计算的时候如果有小数则向上取整



![1751970150342-0c5b14b9-4010-4d9a-90ef-732357bcb8db.png](./img/Pp0EsAJ-SzM9JBrS/1751970150342-0c5b14b9-4010-4d9a-90ef-732357bcb8db-182975.png)







##### 修改抽检比例
同样我们也允许在未通过的质检任务上去修改抽检比例，修改后相应的应检验数量会重新计算

![1751970689417-4992ac89-9bbe-40d6-b1dc-f19867e63b5d.png](./img/Pp0EsAJ-SzM9JBrS/1751970689417-4992ac89-9bbe-40d6-b1dc-f19867e63b5d-367801.png)

##### 修改权限
修改抽检比例是比较敏感和风险操作，所以操作员权限上增加了修改抽检比例的权限。无权限的将不允许修改。

![1752485527152-988f59b7-7334-4429-9744-3386f80cf002.png](./img/Pp0EsAJ-SzM9JBrS/1752485527152-988f59b7-7334-4429-9744-3386f80cf002-675507.png)

#### 质检单
质检单是质检任务完成之后的凭证，用于记录质检任务的结果，一个质检任务产生一个质检单。

![1752027991470-52adbc3a-642a-4e86-a1e8-01edc62f66a0.png](./img/Pp0EsAJ-SzM9JBrS/1752027991470-52adbc3a-642a-4e86-a1e8-01edc62f66a0-521564.png)
