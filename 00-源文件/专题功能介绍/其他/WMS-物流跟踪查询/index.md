# WMS-物流跟踪查询

物流预警

使用场景:

目前各个平台揽收时效基本都是24h(发货到有揽件信息)，而三方仓客户的话，货主会把仓库订单发货时效做为考核的一个标准。当店铺因仓库揽收超时被罚后，货主会让仓库做出相应补偿。

上线效果：

通过设置揽收时效预警，对即将超时订单做揽收操作，降低揽收超时率

操作：

     1.业务配置-出库配置，开启自动订阅物流轨迹，设置生效的线上物流和揽收预警。开启后，订单出库后自动订阅物流轨迹。

2.已出库页面查看订单是否揽收超时。

物流轨迹查询

使用场景

随着客户单量增大，在售问题增加的时候，客服人员往往需要去查询某一问题单的发货物流情况，有些ERP无法提供物流追踪功能，货主会让仓库人员查询各个订单的发货物流进度，方便处理因快递原因产生的问题件。

上线效果

订单查询可通过运单号查询订单物流轨迹详情。

操作

订单查询页面点击运单号查看物流轨迹详情。
