# PDA-快速入库

<font style="color:#374051;">快速入库支持销退预约单不校验商品条码，直接入库。不支持包含序列号商品和生产批次商品的单据入库。</font>

<font style="color:#374051;">一次只支持入库一个单据，扫描匹配到多个时，页面显示匹配到的预约单，支持选择。</font>

![1732169447071-004a551c-00b0-4a45-9275-3ba8660f0342.png](./img/iXwkawj0kg1q7t_S/1732169447071-004a551c-00b0-4a45-9275-3ba8660f0342-938626.png)

### <font style="color:#374051;">01. 校验模式：校验库位</font>
<font style="color:#374051;">多个库位上架模式时，入库明细指导匹配库位，需要扫描库位校验之后才能提交。多个明细的库位相同，只需要扫描一次库位就能完成校验。</font>

<font style="color:#374051;">校验后：库位打上校验标记</font>

![1732170437608-f09e879d-d4ea-484c-bb1e-d22fe7a369b9.png](./img/iXwkawj0kg1q7t_S/1732170437608-f09e879d-d4ea-484c-bb1e-d22fe7a369b9-913904.png)

<font style="color:#374051;">通过选择的库位会打上库位校验标识，无需再次校验。</font>

### <font style="color:#374051;">02. 校验模式：直接提交</font>
<font style="color:#374051;">入库明细有库位时，不需要扫描库位校验，就能直接提交。</font>

![1732170479327-7e7fb64b-f1ba-4a7d-b8d8-d513f5b4a5d2.png](./img/iXwkawj0kg1q7t_S/1732170479327-7e7fb64b-f1ba-4a7d-b8d8-d513f5b4a5d2-927642.png)

### <font style="color:#374051;">03. 指导匹配</font>
<font style="color:#374051;">指导匹配为空时，明细不指导库位，若预约单有默认收货库位，所有明细的库位填充为相同。指导匹配不为空时，会根据指导匹配库位。</font>

<font style="color:#374051;">注：单个库位模式不支持指导匹配。</font>

### <font style="color:#374051;">04.上架模式：单个库位</font>
入库明细仅有1个选择库位入口，多明细入同一库位上。

![1732170102038-b9c03a63-760d-4cac-8dd1-8f4831b84763.png](./img/iXwkawj0kg1q7t_S/1732170102038-b9c03a63-760d-4cac-8dd1-8f4831b84763-004286.png)

### <font style="color:#374051;">05.上架模式：多个库位</font>
 每条明细显示选择库位入口，支持多明细入多库位。

![1732170336065-6ff7bab0-7f7f-48cb-a7f2-1caf74d8f42e.png](./img/iXwkawj0kg1q7t_S/1732170336065-6ff7bab0-7f7f-48cb-a7f2-1caf74d8f42e-858378.png)

支持指导匹配。

### 06.原订单备注
显示原始WD订单上的订单备注，可点击查看更多内容。

![1745916890918-b61ef0f9-ef8c-4f91-b985-1477cfbbfc16.png](./img/iXwkawj0kg1q7t_S/1745916890918-b61ef0f9-ef8c-4f91-b985-1477cfbbfc16-746040.png)

### 07.上传图片
点击进入上传图片页面，可选择通过拍照或相册直接上传图片。
