# 万里牛 WMS 拆解与产品设计参考

本项目面向仓储物流产品经理、供应链系统工程师与仓储运营人员，围绕万里牛电商云仓 WMS 进行系统化业务拆解与产品建模。项目将原始帮助手册与专题资料进行工程化分层沉淀，提炼作业事实、核心流程、产品设计抽象与字段参考。

## 项目解决的问题

通用型电商 WMS 的业务规则碎片化严重，帮助文档往往分散在数百个操作单页中，缺乏全局视角与产品建模沉淀。本项目将原始零散资料组织成清晰的业务递进链路：

```text
原始资料归档 → 业务事实重构 → 核心作业流程 → 产品设计沉淀 → 业务字段参考 → 设计验收
```

## 资料分层目录

```text
00-源文件/                         完整归档的原始语雀操作手册、专题功能与PDA文档
01-按章节拆分的md文件/              按业务主线重构聚合后的高密度业务事实层
02-按章节拆分的流程图/              端到端作业流、状态机与关键分支Mermaid流程图
03-WMS产品设计精华知识借鉴/         电商SaaS仓储核心设计模式、状态机与设计取舍
04-WMS的字段设计参考借鉴/           核心单据与库存实体的字段模型、字段来源与验收参考

本轮全面走查的入口：[全面走查与学习地图](00-全面走查与学习地图.md)。新手建议先看其中的跨章节主链，再按 01 → 02 → 03 → 04 逐层深入。
```
