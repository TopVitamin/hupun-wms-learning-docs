# 14 状态、数量与操作矩阵

> 本文件把各章节的状态和数量口径统一起来。它是设计参考，不代表万里牛已经存在一套完全统一的内部状态机。
> 参考范围：`03-WMS产品设计精华知识借鉴/00-总体设计方法与跨模块基线.md`、`01-按章节拆分的md文件/04-入库操作.md`、`01-按章节拆分的md文件/05-出库_B2C.md`、`01-按章节拆分的md文件/08-库存管理.md`。

## 1. 四层状态模型

| 层级 | 表达什么 | 典型对象 | 不应混淆 |
| :--- | :--- | :--- | :--- |
| 主数据层 | 对象是否可被新业务引用 | 商品、库位、承运商、策略 | 不代表历史数据被删除 |
| 业务单据层 | 业务意图是否有效、是否完成 | 入库预约、入库单、出库订单、盘点单 | 不代表现场任务已完成 |
| 执行任务层 | 现场工作进度 | 收货、上架、拣货、设备任务 | 不代表库存一定已生效 |
| 库存与同步层 | 数量结果和外部回写状态 | 库存余额、库存流水、同步记录 | 外部失败不覆盖内部业务状态 |

## 2. 核心对象状态矩阵

| 对象 | 建议状态 | 进入条件 | 典型操作 | 库存影响 |
| :--- | :--- | :--- | :--- | :--- |
| 主数据 | 草稿、启用、停用 | 新增、校验、停用 | 编辑、启用、停用 | 不直接影响库存 |
| 入库预约 | 在途、部分收货、收货完成、关闭 | 创建、收货、关闭 | 收货、查看差异、关闭 | 创建预约不增加实际库存 |
| 入库单 | 待确认、审批中、已确认、已关闭 | 收货/清点/审批 | 确认、驳回、撤销、关闭 | 以明确生效节点为准 |
| 出库订单 | 待审核、待分配、作业中、部分发货、已发货、取消 | 接单、审核、发货 | 审核、分配、取消、发货 | 分配可能增加锁定，生效减少实际库存 |
| 波次 | 待生成、待执行、作业中、完成、取消 | 策略命中 | 生成、执行、取消 | 不直接改库存 |
| 作业任务 | 待领取、作业中、部分完成、完成、失败、取消、解绑 | 业务对象生成 | 领取、解绑、提交、重试 | 由领域任务决定是否生效库存 |
| 盘点单 | 待作业、作业中、完成、关闭 | 创建盘点范围 | 盘点、确认差异、关闭 | 盘点本身不等于库存调整 |
| 库存调整单 | 草稿、待审批、已生效、取消 | 差异确认 | 提交、审批、调整 | 生效后产生调整流水 |
| 外部同步 | 待处理、处理中、成功、失败、重试中 | 发送/接收消息 | 重试、查看错误、人工补偿 | 不覆盖 WMS 内部状态 |

## 3. 状态动作规则

| 当前状态 | 允许动作 | 动作后结果 | 需要保留的证据 |
| :--- | :--- | :--- | :--- |
| 草稿 | 编辑、提交、取消 | 提交后进入待处理/审批中 | 编辑人、提交时间、版本 |
| 待处理/待领取 | 领取、取消、关闭 | 进入作业中或取消 | 领取人和时间 |
| 作业中 | 提交、部分完成、解绑、异常 | 完成、部分完成、失败或重新待领取 | 已完成量、剩余量、异常原因 |
| 审批中 | 通过、驳回、撤销 | 生效、退回修改或撤销 | 审批人、意见、时间 |
| 失败 | 查看原因、修复、重试、关闭 | 重试中、成功或关闭 | 错误编码、重试次数、请求标识 |
| 已完成/已生效 | 查询、反向单据 | 生成冲销或反向结果 | 原单、反向单、操作人、原因 |
| 已取消/已关闭 | 查询 | 不再接受正常新操作 | 取消/关闭原因和时间 |

## 4. 数量关系矩阵

| 业务阶段 | 主要数量 | 数量关系或含义 | 备注 |
| :--- | :--- | :--- | :--- |
| 入库计划 | 计划数量 | 来源单据希望入库的数量 | 不因短收直接改写 |
| 入库现场 | 实收数量 | 收货员实际清点/扫描数量 | 可以分批累计 |
| 入库差异 | 差异数量 | 实收与计划的差额 | 必须有原因或处理决定 |
| 出库需求 | 订单需求数量 | 客户或上游要求发出的数量 | 原始需求快照 |
| 出库分配 | 已分配数量 | 系统为订单找到库存的数量 | 可能形成锁定 |
| 出库执行 | 已拣货数量 | 现场从库位实际取出的数量 | 可能部分完成或报缺 |
| 出库发运 | 已发货数量 | 已形成发运结果的数量 | 多包裹时按明细累计 |
| 库存账面 | 实际库存 | 仓库实际拥有的账面数量 | 操作手册明确 |
| 库存可售 | 可用库存 | `实际库存 - 锁定库存 - 冻结库存` | 操作手册明确 |
| 库存占用 | 锁定库存 | 已被订单或作业占用的数量 | 不应再次分配 |
| 库存隔离 | 冻结库存 | 不能正常使用的数量 | 解冻要有来源 |
| 入库在途 | 在途库存 | 已产生入库意图但尚未入库的数量 | 不计入实际库存总量 |

## 5. 业务动作与库存结果

| 动作 | 单据/任务结果 | 库存结果 | 必须保留 |
| :--- | :--- | :--- | :--- |
| 创建入库预约 | 预约在途 | 不增加实际库存 | 来源单、计划量 |
| 收货/清点 | 收货记录或清点记录 | 是否增加库存待确认 | 实收、差异、批次和操作人 |
| 确认入库 | 入库单生效 | 增加实际库存 | 入库单、库位、流水 |
| 出库分配 | 订单进入已分配 | 增加锁定、减少可用的口径需统一 | 分配库位、数量、规则版本 |
| 拣货确认 | 任务完成或部分完成 | 是否在此时减少实际库存待确认 | 拣货数量、异常和任务 |
| 出库生效 | 出库单/包裹完成 | 减少实际库存 | 出库单、包裹、运单、流水 |
| 移库 | 移库任务完成 | 来源库位减少、目标库位增加，仓库总量不变 | 来源/目标、数量、流水 |
| 冻结 | 冻结记录生效 | 可用库存减少，实际库存通常不变 | 冻结原因、数量和来源 |
| 盘点 | 盘点完成 | 不直接改变库存 | 基准量、实盘量、差异量 |
| 库存调整 | 调整单生效 | 按正负差异改变库存 | 原因、审批、前后数量 |

## 6. 待确认事项

1. 收货、确认入库、上架确认和库存增加的准确节点。
2. 拣货确认、复核完成、出库生效和实际库存扣减的准确节点。
3. 锁定库存、作业中数量和预占数量是否为不同数据对象。
4. 盘点期间是否冻结库存以及并发业务如何处理。
5. 所有反向处理是否必须生成反向单据和冲销流水。
