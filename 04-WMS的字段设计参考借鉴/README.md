# 04 WMS 字段设计参考借鉴

## 1. 目录定位

本目录面向 WMS 产品设计、数据建模和研发沟通，按设计模块整理：

1. 操作手册中出现了哪些业务对象和字段信息；
2. 这些字段在什么业务环节产生、读取和校验；
3. 哪些字段是通用 WMS 核心，哪些属于行业、平台、设备或接口扩展；
4. 资料没有说明的地方，应该如何标记和继续确认。

本目录不是万里牛真实数据库结构说明书。当前资料以操作手册和产品设计借鉴文档为主，未发现独立的数据字典文件。因此，字段编码、数据库类型、长度和约束如果没有原始数据字典支持，必须标记为“建议设计”或“待确认”。

## 5. 当前整理状态

当前文件范围为 `00–20`，共 21 个 Markdown 文件（不含 README）。字段编码、格式和数据库类型仍属于建议设计；后续如果获得真实数据字典，再增加原始字段映射，不直接覆盖当前的业务设计参考模型。

## 6. 新手使用方法

字段设计不要从“字段越全越好”开始。先在 01 层确认业务事实，再在 03 层确认对象边界，最后逐字段回答：字段来自哪里、何时产生、谁能改、如何校验、被谁消费、异常时怎么保留证据。

推荐使用 [20-原始字段观察与设计验收](20-原始字段观察与设计验收.md) 做最后检查。该文档中的字段名是建议模型，不代表万里牛真实数据库字段；凡是原文没有说明的类型、长度、唯一性、审批和接口约束，都应继续标记为“待确认”。
