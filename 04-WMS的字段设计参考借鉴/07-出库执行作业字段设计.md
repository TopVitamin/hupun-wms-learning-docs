# 07 出库执行作业字段设计

> 参考范围：`01-按章节拆分的md文件/03-仓内策略.md`、`01-按章节拆分的md文件/05-出库_B2C.md`、`01-按章节拆分的md文件/06-大宗_B2B.md`、`01-按章节拆分的md文件/10-打印与电子面单.md`、`03-WMS产品设计精华知识借鉴/07-出库执行作业设计.md`
> 字段编码、长度和数据库属性均为建议设计，除非另有原始数据字典依据。

## 1. 本章范围

### 1.1 包含哪些模块

库存分配、波次、零拣、整箱/容器拣货、接力拣货、播种、验货、复核、打包、称重、打印、出库和承运商交接。

### 1.2 包含哪些功能

波次生成、任务拆分、任务领取、库位拣货、报缺、容器绑定、订单验货、抽检、播种、包装、批量称重、面单打印和出库交接。

### 1.3 业务场景与要解决的问题

参考资料覆盖 PC 和 PDA 的零拣、波次拣货、容器拣货、接力拣货、播种、自由验货、抽检、批量称重、大宗装箱和承运商交接。字段必须把“系统分配了什么”和“现场实际完成了什么”分开。

## 2. 业务对象与逻辑表

| 逻辑对象 | 主要职责 | 关系 | 采用建议 |
| :--- | :--- | :--- | :--- |
| 波次 | 组织一批订单和作业条件 | 订单 1:N 波次关联 | P0 |
| 分配记录 | 保存订单行与库存库位的分配 | 订单行 1:N 分配 | P0 |
| 拣货任务/明细 | 表达现场取货工作 | 波次 1:N 任务 | P0 |
| 验货/复核记录 | 保存扫描核对结果 | 任务/订单 1:N 记录 | P0 |
| 包装/称重记录 | 保存包裹和重量 | 订单 1:N 包裹 | P0 |
| 出库交接记录 | 保存承运商交接结果 | 包裹/运单关联 | P1 |

## 3. 字段设计原则

- 波次、任务、订单和包裹是不同对象，不能用一个编号贯穿全部层级。
- 分配数量、拣货数量、验货数量、打包数量和发货数量分别记录。
- 拣货确认、出库生效和物流交接可能不是同一时间，库存和订单状态要分别处理。
- 容器、拣货框、包裹和运单是不同载体，不能以一个“箱号”字段替代。
- PDA 扫描产生的是现场操作事实，PC 页面展示的是聚合结果，二者都要保留来源和操作人。

## 4. 字段定义与设计说明

### 4.1 波次与分配 `wave` / `allocation_record`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `wave_id` | 波次标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `wave_no` | 波次号 | 业务编号 | VARCHAR | 必填 |
| `wave_type` | 波次类型 | 普通/预配/自由/一筐同品等 | ENUM | 必填 |
| `strategy_version_id` | 使用策略版本 | 关联 ID | BIGINT/UUID | 自动生成时建议必填 |
| `order_count` | 订单数 | 整数 | INT | 系统汇总 |
| `status` | 波次状态 | 待生成/待拣货/作业中/完成/取消 | ENUM | 默认待处理 |
| `allocation_id` | 分配记录标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `outbound_line_id` | 出库明细 | 关联 ID | BIGINT/UUID | 必填 |
| `location_id` | 分配来源库位 | 关联 ID | BIGINT/UUID | 必填 |
| `allocated_qty` | 分配数量 | 数量 | DECIMAL | 必填 |
| `allocation_status` | 分配状态 | 已分配/释放/部分拣货/完成 | ENUM | 默认已分配 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `wave_type` | 波次生成时确定 | 类型决定分组、拣货和验货方式，不能只作为页面标签 | 支持新型履约路径 | 让不同订单进入合适的作业链 | 参考事实＋建议设计 |
| `strategy_version_id` | 策略命中后写入 | 必须知道波次为什么这样分组 | 支持规则复盘和效果分析 | 解释自动分波结果 | 建议设计 |
| `location_id` / `allocated_qty` | 分配时写入 | 分配库位和现场实际拣货库位可能不同，需保留差异 | 支持缺货、短拣和库位准确率 | 让分配结果可执行 | 归纳判断＋建议设计 |
| `allocation_status` | 拣货、释放或异常时更新 | 释放必须归还可分配库存或进入异常处理 | 支持报缺和重新分配 | 防止库存被长期占用 | 建议设计 |

### 4.2 拣货任务 `pick_task` / `pick_task_line`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `pick_task_id` | 拣货任务标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `pick_task_no` | 拣货任务号 | 业务编号 | VARCHAR | 必填 |
| `wave_id` | 所属波次 | 关联 ID | BIGINT/UUID | 可选，零拣场景待确认 |
| `operator_id` | 领取/作业人员 | 用户 ID | BIGINT/UUID | 作业中必填 |
| `container_id` | 拣货容器 | 关联 ID | BIGINT/UUID | 容器作业时必填 |
| `source_location_id` | 来源库位 | 关联 ID | BIGINT/UUID | 必填 |
| `product_id` | 商品/SKU | 关联 ID | BIGINT/UUID | 必填 |
| `required_qty` | 应拣数量 | 数量 | DECIMAL | 必填 |
| `picked_qty` | 已拣数量 | 数量 | DECIMAL | 默认 0 |
| `shortage_qty` | 报缺数量 | 数量 | DECIMAL | 默认 0 |
| `status` | 任务状态 | 待领取/作业中/部分完成/完成/解绑 | ENUM | 默认待领取 |
| `exception_reason` | 异常原因 | 原因编码/文本 | VARCHAR/ENUM | 异常时必填 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `operator_id` / `status` | 领取、解绑、提交时更新 | 支持多人领取和重新领取，不能只记录最后一个人 | 支持绩效和任务追责 | 避免任务重复执行 | 参考事实＋建议设计 |
| `source_location_id` / `container_id` | 分配或拣货时写入 | 来源库位、拣货容器和订单归属需一致 | 支持容器拣货、接力拣货和播种 | 现场知道去哪里取、放到哪里 | 参考事实＋建议设计 |
| `required_qty` / `picked_qty` / `shortage_qty` | 任务生成、扫描和报缺时更新 | 报缺不能直接改应拣数量；部分完成要保留剩余 | 支持缺货分析和补拣 | 解释为什么订单未足量完成 | 建议设计 |
| `exception_reason` | 报缺、错拣或任务关闭时写入 | 原因需要可统计，不能全靠备注 | 支持异常任务池 | 让现场异常可被复盘 | 建议设计 |

### 4.3 验货、包装、称重与交接 `verification` / `package_operation`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `verification_id` | 验货记录标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `verified_qty` | 已验数量 | 数量 | DECIMAL | 必填 |
| `verification_result` | 验货结果 | 通过/差异/失败 | ENUM | 必填 |
| `package_id` | 包裹 | 关联 ID | BIGINT/UUID | 打包后必填 |
| `package_material_code` | 耗材编码 | 编码 | VARCHAR | 使用耗材时可选 |
| `gross_weight` | 包裹毛重 | 数值＋单位 | DECIMAL | 称重时写入 |
| `weighed_at` | 称重时间 | 日期时间 | DATETIME | 称重后写入 |
| `carrier_id` | 承运商 | 关联 ID | BIGINT/UUID | 交接时必填 |
| `handover_status` | 交接状态 | 待交接/已交接/异常 | ENUM | 默认待交接 |
| `handover_at` | 交接时间 | 日期时间 | DATETIME | 交接后写入 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `verified_qty` / `verification_result` | 扫码验货或抽检后写入 | 需区分全量验货、抽检和自由验货，不能把“通过”理解为全量完成 | 支持错拣率和复核绩效 | 防止错误商品进入包裹 | 参考事实＋建议设计 |
| `package_id` / `package_material_code` | 打包时生成或选择 | 包裹与订单、明细和耗材要能互查 | 支持耗材成本和多包裹 | 解释商品如何进入包裹 | 建议设计 |
| `gross_weight` / `weighed_at` | 电子秤或人工称重时写入 | 要明确毛重、单位和修改权限 | 支持运费和重量异常 | 防止承运商计费错误 | 参考事实＋待确认 |
| `handover_status` / `handover_at` | 承运商交接时更新 | 交接不等同于出库生效，二者需有明确边界 | 支持交接批次和物流追踪 | 确认货物是否已交给承运商 | 建议设计＋待确认 |

## 5. 功能与首版取舍

| 优先级 | 功能 | 主要字段 | 取舍判断 |
| :--- | :--- | :--- | :--- |
| P0 | 波次、分配和拣货任务 | 波次、库位、任务、数量 | 覆盖核心订单履约 |
| P0 | 扫描验货和数量差异 | 验货数量、结果、异常 | 防止错拣漏拣 |
| P0 | 包装、称重和出库交接 | 包裹、重量、承运商 | 形成发运结果 |
| P1 | 容器拣货、播种、接力和抽检 | 容器、分拣位、检验模式 | 按仓库作业方式启用 |
| P1 | PDA 与 PC 协同 | 设备、操作人、来源 | 保留同一任务的多端记录 |
| 后续 | 自动化拣选和智能路径 | 设备任务、路径参数 | 条件能力，不预设厂商字段 |

## 6. 跨模块依赖、拓展与待确认

- 读取出库订单、库存分配、库位、容器、策略和承运商信息；任务完成结果回写 06 章订单和 08 章库存。
- 可拓展到多容器播种、自动化拣货、耗材推荐、重量计费、视频追溯和承运商交接批次。
- 拣货确认与库存扣减、验货与出库生效、交接与物流回传的时点和逆向处理规则，均待确认。
