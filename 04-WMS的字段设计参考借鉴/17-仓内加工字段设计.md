# 17 仓内加工字段设计

> 参考范围：`00-源文件/操作手册/仓内作业/加工/仓内加工.md`、`00-源文件/操作手册/仓内作业/加工/加工任务.md`、`00-源文件/PDA安卓端/仓内/PDA-快速加工.md`、`00-源文件/PDA安卓端/仓内/PDA-加工领料.md`、`01-按章节拆分的md文件/07-仓内作业.md`、`03-WMS产品设计精华知识借鉴/13-仓内加工与作业结果设计.md`。

字段编码、类型和长度均为建议设计，不代表万里牛真实数据库字段。

## 1. 本章范围

覆盖组合加工、拆分加工、原料锁定、加工任务、实际用量、成品完成数量、退料和ERP通知结果。不覆盖生产制造中的工艺路线、BOM版本、MRP和成本核算。

## 2. 业务对象与逻辑表

| 逻辑对象 | 主要职责 | 关系 | 采用建议 |
|---|---|---|---|
| 加工单 | 表达一项加工意图 | 1:N加工明细 | P0 |
| 加工明细 | 区分原料/成品、计划量和配比 | 一个加工单含原料行和成品行 | P0 |
| 原料锁定明细 | 保存原料来源库位和锁定数量 | 加工明细1:N锁定明细 | P0 |
| 加工任务 | 组织多个加工单现场作业 | 任务1:N加工单 | P0 |
| 加工实际记录 | 保存实际消耗和成品结果 | 加工单/任务1:N记录 | P0 |
| 退料记录 | 保存未使用原料退回 | 实际记录1:N退料 | P0 |
| 外部通知记录 | 保存加工结果通知ERP | 加工结果1:N通知记录 | P1 |

## 3. 字段定义与设计说明

### 3.1 加工单与明细

| 字段编码（建议） | 字段名称 | 格式/类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `process_order_no` | 加工单号 | VARCHAR | 系统生成或外部带入 | ERP推送/手工创建 | 作为加工单追溯身份 |
| `process_type` | 加工类型 | ENUM：组合/拆分 | 必填 | 创建时确定 | 决定原料/成品方向和配比校验 |
| `owner_id` / `warehouse_id` | 货主/仓库 | ID | 按场景必填 | 来源映射或选择 | 影响库存范围、任务合并和权限 |
| `external_status` | 外部状态 | ENUM/文本 | 对接场景使用 | ERP推送或关闭时更新 | 外部关闭可能触发退料提示 |
| `process_status` | 加工单状态 | ENUM | 系统生成 | 建单、领料、加工、关闭 | 不能用任务状态替代 |
| `source_task_no` | 外部任务号 | VARCHAR | ERP带任务号时必填 | 自动生成任务时写入 | 支持任务幂等和外部回传 |
| `line_role` | 明细角色 | ENUM：原料/成品 | 必填 | 创建明细时写入 | 不能只用正负数量判断角色 |
| `product_id` / `unit_code` | 商品/单位 | ID/VARCHAR | 必填 | 来源或人工选择 | 引用商品、单位和批次规则 |
| `planned_qty` / `actual_qty` | 计划量/实际量 | DECIMAL | 计划必填，实际确认时写入 | 建单/确认加工 | 原料实际量可与计划不同，需保留差异 |
| `ratio_qty` | 配比数量 | DECIMAL | 按加工类型必填 | 建单或计算 | 支撑组合/拆分结果计算，不等于实际消耗 |

### 3.2 库位、批次与退料

| 字段编码（建议） | 字段名称 | 格式/类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `locked_location_id` | 原料锁定库位 | ID | 原料锁定成功时必填 | 库位锁定 | 一个原料可对应多个锁定库位 |
| `locked_qty` / `picked_qty` | 锁定量/已拣量 | DECIMAL | 系统累计 | 锁定/领料 | 区分“系统占用”和“实际取出” |
| `lot_no` / `production_date` / `expiry_date` | 批次、生产日期、过期日期 | VARCHAR/DATE | 按商品和模式 | 锁定或加工确认 | 批次严格模式按原文规则匹配 |
| `return_qty` | 退料数量 | DECIMAL | 大于0时必填 | 确认加工前计算或录入 | 原文要求退料数量>0时填写退料库位 |
| `return_location_id` | 退料库位 | ID | 退料时必填 | 退料提交 | 退料回库后形成库存记录 |
| `finished_qty` | 成品完成数量 | DECIMAL | 确认加工时必填 | 加工确认 | 原文允许小于或大于计划量，是否审批待确认 |
| `inventory_attr` | 库存属性 | ENUM | 按商品/场景 | 加工结果写入 | 正次品必须与库位和库存规则兼容 |

### 3.3 任务与通知

| 字段编码（建议） | 字段名称 | 格式/类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `process_task_no` | 加工任务号 | VARCHAR | 生成任务时必填 | 手动或ERP自动生成 | 任务与加工单一对多关联 |
| `task_status` | 任务状态 | ENUM：待领料/待加工/作业中/完成/关闭/取消 | 系统生成 | 领取、确认、撤销 | 已领取/已完成不可直接撤销 |
| `operator_id` / `completed_at` | 加工员/完成时间 | ID/DATETIME | 确认时必填 | 加工确认 | 支持责任追溯和绩效 |
| `notification_status` | ERP通知状态 | ENUM：待通知/成功/失败/重试 | 对接场景 | 结果通知时更新 | 通知失败不能把加工单误标为完成 |
| `notification_error` | 通知失败原因 | TEXT | 失败时必填 | 通知失败时写入 | 支持重试和运维定位 |

## 4. 数量关系与库存影响

| 数量 | 关系 |
|---|---|
| 原料计划量 | 加工单计划消耗，不等于最终实际消耗 |
| 原料锁定量 | 按库位和批次占用的可用库存 |
| 原料已拣量 | 已从来源库位取出、进入待加工的数量 |
| 原料实际用量 | 确认加工时真正消耗的数量 |
| 退料量 | `已拣量-实际用量`在需要退料的场景下形成，具体计算按原文和配置执行 |
| 成品计划量 | 加工目标数量 |
| 成品完成量 | 实际生成数量，原文允许与计划不同 |

库存生效节点必须结合目标系统确认。至少要保证原料减少、成品增加、退料回库和ERP通知都能关联同一加工结果，不能只修改加工单状态。

## 5. 设计验收清单

- 组合加工和拆分加工是否通过`process_type`区分？
- 原料/成品、计划/实际、锁定/已拣/消耗是否分别有字段？
- 一个原料跨多个库位时是否能保存多条锁定明细？
- 部分领料、加工单关闭、任务撤销是否都能处理退料？
- 批次严格模式下，原料批次和成品批次是否保留实际匹配结果？
- 加工完成通知ERP失败时，是否能重试且不重复产生库存结果？
