# 19 3PL费用与货主结算字段设计

> 参考范围：`00-源文件/操作手册/财务/费用统计/货主费率配置.md`、`00-源文件/操作手册/财务/费用统计/货主增值费用.md`、`00-源文件/操作手册/财务/费用统计/货主费用明细.md`、`00-源文件/操作手册/财务/费用统计/货主费用统计.md`、`00-源文件/操作手册/财务/费用统计/货主账单.md`、`00-源文件/操作手册/财务/对账/承运商对账.md`、`00-源文件/操作手册/财务/发票/发票配置.md`、`00-源文件/操作手册/财务/发票/发票打印.md`、`01-按章节拆分的md文件/11-客服与财务.md`、`03-WMS产品设计精华知识借鉴/14-3PL费用货主协同与结算设计.md`。

字段编码、类型和长度均为建议设计；原文明确货主费率配置仅对开启3PL的公司开放。

## 1. 本章范围

覆盖货主费率、出库费用、出库运费、入库费用、存储费用、增值费用、费用审核、费用重算/冲红、承运商对账、货主账单、货主充值/单量和发票。税务系统的完整开票流程不在当前资料范围内。

## 2. 业务对象与逻辑表

| 逻辑对象 | 主要职责 | 关系 | 采用建议 |
|---|---|---|---|
| 费率规则 | 定义货主、仓库、单据类型下的计费方式 | 规则1:N区间/阶梯 | 3PL条件能力 |
| 费用明细 | 保存一条业务费用结果 | 业务事实1:N费用 | P0/条件 |
| 增值费用 | 保存人工或导入的包装、清点、维修等费用 | 关联单据可选 | P1/条件 |
| 承运商对账记录 | 对比承运商成本和系统预估成本 | 对账任务1:N订单结果 | P1 |
| 货主账单模板 | 定义账期、明细字段和顺序 | 模板1:N账单 | P1 |
| 货主账单 | 固化某仓库、货主和时间范围的结算结果 | 账单1:N费用明细 | P1 |
| 发票 | 保存开票信息和打印结果 | 发票关联账单/费用 | 按财务边界采用 |
| 充值/单量记录 | 保存货主余额、单量或金额扣减 | 货主1:N变动记录 | 条件能力 |

## 3. 字段定义与设计说明

### 3.1 费率规则

| 字段编码（建议） | 字段名称 | 类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `rate_rule_id` / `rate_rule_no` | 费率规则标识/编码 | ID/VARCHAR | 系统生成 | 新增规则 | 规则查询和版本引用 |
| `warehouse_id` / `owner_id` | 仓库/货主 | ID | 必填 | 规则配置 | 货主费率的核心作用域 |
| `document_type` | 单据类型 | ENUM | 按费用类型必填 | 规则配置 | 出库、入库、盘点、加工、移库等场景引用 |
| `fee_category` | 费用分类 | ENUM：操作费/物料使用费/动态费用/固定费用 | 必填 | 规则配置 | 决定可配置的计费方式 |
| `billing_method` | 计费方式 | ENUM | 必填 | 规则配置 | 按单、数量、种类、重量、体积、库位、日库存等 |
| `tier_config` | 区间/首计/续计配置 | JSON或明细表 | 按方式必填 | 规则配置 | 区间边界、首数量、续数量和价格必须可解释 |
| `settlement_timing` | 出账时间 | ENUM/规则 | 运费场景必填 | 规则配置 | 业务完成后或每月定时计算 |
| `effective_from` / `effective_to` | 生效区间 | DATETIME | 建议必填 | 发布/停用 | 历史费用需引用实际使用的规则版本 |

### 3.2 费用明细与增值费用

| 字段编码（建议） | 字段名称 | 类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `fee_detail_no` | 费用明细号 | VARCHAR | 系统生成 | 计算或新增费用 | 费用追溯身份 |
| `fee_type` / `fee_name` | 费用类型/名称 | ENUM/VARCHAR | 有效费用必填 | 规则匹配或人工选择 | 区分出库费用、运费、入库费用、存储费用和增值费用 |
| `source_document_type` / `source_document_no` | 关联单据类型/编码 | ENUM/VARCHAR | 按场景必填 | 业务完成或人工新增 | 增值费用原文支持出库、入库、盘点、加工、移库 |
| `warehouse_id` / `owner_id` | 仓库/货主 | ID | 费用明细必填 | 来源业务或人工新增 | 查询、权限和账单范围 |
| `billing_qty` | 计费数量 | DECIMAL | 按计费方式必填 | 规则计算或导入 | 应能回到库存、订单、包裹或单据事实 |
| `unit_price` | 计费单价 | DECIMAL | 按方式必填 | 规则带出或人工修改 | 原文增值费用允许负数；其他场景需确认 |
| `fee_amount` | 产生费用 | DECIMAL | 有效费用必填 | `计费单价×计费数量`或规则计算 | 负数可作为冲正，但不得覆盖原记录 |
| `fee_status` | 费用状态 | ENUM：待审核/已生效/冲红/作废 | 系统生成 | 审核、重算或冲正 | 生效后进入明细、统计和账单 |
| `created_at` / `business_at` | 创建时间/业务时间 | DATETIME | 系统生成 | 费用生成时写入 | 统计时间不能混用 |
| `original_fee_id` | 原费用记录 | ID | 冲红时必填 | 纠正费用时写入 | 建立冲正链，不删除历史 |

### 3.3 账单、对账、充值与发票

| 字段编码（建议） | 字段名称 | 类型 | 必填/默认 | 来源/写入时机 | 校验与下游影响 |
|---|---|---|---|---|---|
| `bill_template_id` / `bill_template_name` | 账单模板 | ID/VARCHAR | 生成账单前必填 | 模板配置 | 定义账期、明细和导出顺序 |
| `billing_period_from` / `billing_period_to` | 费用时间范围 | DATE/DATETIME | 必填 | 新增账单 | 原文新增账单时间间隔不超过2个月，需保留校验 |
| `include_detail` / `by_package` | 是否含明细/按包裹生成 | BOOLEAN | 模板配置 | 模板或账单生成 | 支持多包裹/子母件维度导出 |
| `bill_status` | 账单状态 | ENUM：待对账/已对账/已下载等 | 系统生成 | 新增、对账、下载 | 原文对账后不能删除 |
| `reconciliation_task_no` | 对账任务号 | VARCHAR | 导入对账时必填 | 承运商文件导入 | 支持异步任务、结果下载和失败定位 |
| `reconciled_cost` / `estimated_cost` | 对账成本/预估成本 | DECIMAL | 按对账结果 | 对账或重算 | 区分系统预估和承运商实际成本 |
| `reconciliation_status` | 对账状态 | ENUM | 系统生成 | 对账、核销 | 核销规则和时间限制按承运商场景确认 |
| `balance_change` / `quantity_change` | 金额/单量变动 | DECIMAL | 充值或扣减时必填 | 货主充值、审核或取消订单 | 变动记录需有原因和来源 |
| `invoice_no` / `invoice_amount` | 发票号/开票金额 | VARCHAR/DECIMAL | 开票后写入 | 发票配置或打印 | 需要关联账单和费用范围 |

## 4. 核心口径

| 口径 | 原文事实 | 字段设计要求 |
|---|---|---|
| 费用范围 | 货主费用明细支持出库费用、出库运费、入库费用、存储费用；存储费用无单据 | `source_document_no`允许为空，但必须有统计日期和计费范围 |
| 增值费 | 关联单据类型包括出库单、入库单、盘点单、加工单、移库单；金额为空或0时费用无效 | 关联类型和编码不能只靠自由文本，导入和手工入口要区分校验强度 |
| 存储费 | 可按商品日库存、体积、重量、周转天数、日使用库位或日固定费用计费 | 需要`calculation_date`、库存口径和规则版本 |
| 冲正 | 增值费用的计费单价和产生费用可为负数，用于审核后纠正 | 负数记录要保留原费用关联和原因 |
| 账单 | 可按月或选定时间生成，可选择汇总或明细、按费用项或按订单汇总、按包裹生成 | 模板字段和账单实例字段分开，导出结果可复核 |

## 5. 设计验收清单

- 费用明细能否回到货主、仓库、费用类型、计费数量、单价、来源事实和规则版本？
- 存储费用无单据时，是否仍能回到某天的库存或库位统计？
- 计费规则变更后，历史费用是否保留旧规则快照？
- 重算、冲红、删除和作废是否区分，是否都保留操作人和原因？
- 账单对账后是否禁止删除，账单下载是否受模板变更影响？
- 承运商实际成本、货主应收费用和发票金额是否明确为同一或不同口径？
