# 02 仓库空间与作业资源字段设计

> 参考范围：`01-按章节拆分的md文件/01-基础信息与系统设置.md`、`01-按章节拆分的md文件/03-仓内策略.md`、`01-按章节拆分的md文件/07-仓内作业.md`、`03-WMS产品设计精华知识借鉴/02-仓库空间与作业资源设计.md`
> 字段编码、长度和数据库属性均为建议设计，除非另有原始数据字典依据。

## 1. 本章范围

### 1.1 包含哪些模块

仓库、区域、库区、库位、库位用途与类型、容器、工位、设备覆盖范围和设备任务边界。

### 1.2 包含哪些功能

空间层级维护、库位条码、库位使用方式、容量限重、混放约束、库位优先级、存储条件、容器绑定和设备范围配置。

### 1.3 业务场景与要解决的问题

操作手册明确区域用于业务隔离、库区用于功能和工作分配、库位用于精准定位；库位还参与拣货、补货、上架、盘点和异常暂存。字段设计要解决“货物在哪”“谁在什么区域作业”“库位能否承接该货物”和“设备任务覆盖哪里”等问题。

## 2. 业务对象与逻辑表

| 逻辑对象 | 主要职责 | 关系 | 采用建议 |
| :--- | :--- | :--- | :--- |
| 仓库 | 业务和库存的最高空间归属 | 仓库 1:N 区域 | P0 |
| 区域 | 业务隔离或楼层/平面范围 | 区域 1:N 库区 | P0 |
| 库区 | 功能分区和工作分配 | 库区 1:N 库位 | P0 |
| 库位 | 最小物理定位单元 | 被库存、任务和策略引用 | P0 |
| 容器/工位 | 现场载体或作业位置 | 与库位、任务和作业记录关联 | P0/P1 |
| 设备范围/设备任务 | 约束自动化作业边界 | 设备 N:M 库位 | 后置或条件采用 |

## 3. 字段设计原则

- 空间层级必须能从仓库追溯到区域、库区和库位，库位编码不能代替层级关系。
- 库位用途和库位类型分开：前者决定能承接什么作业，后者描述物理承载形式。
- 容量、承重、存储条件、混放和库存属性属于库位选择约束，不只是展示字段。
- 库位已存在库存、锁定或在途任务时，关键属性不能直接修改。
- 设备覆盖范围只定义任务边界；设备协议和实际库存生效由集成、任务和库存模块负责。

## 4. 字段定义与设计说明

### 4.1 仓库、区域、库区 `warehouse` / `area` / `zone`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `warehouse_id` | 仓库标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `warehouse_code` | 仓库编码 | 编码 | VARCHAR，长度待确认 | 必填 |
| `warehouse_name` | 仓库名称 | 文本 | VARCHAR | 必填 |
| `area_code` | 区域编码 | 编码 | VARCHAR | 必填 |
| `zone_code` | 库区编码 | 编码 | VARCHAR | 必填 |
| `zone_usage_type` | 库区用途 | 收货/存储/拣选/异常等 | ENUM | 待确认 |
| `status` | 空间状态 | 启用/停用 | ENUM | 默认启用 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `warehouse_code` | 仓库建档 | 编码是库存、权限和接口的稳定关联键 | 支持多仓查询和货主授权 | 区分不同物理仓或逻辑仓 | 参考事实＋建议设计 |
| `area_code` | 空间建模 | 区域用于业务隔离，不能只作为名称 | 支持楼层、温区或作业范围隔离 | 避免补货、移库跨越不允许的区域 | 参考事实＋归纳判断 |
| `zone_code` / `zone_usage_type` | 库区建档 | 库区用途影响任务分配和库位选择 | 支持拣选区、整存区、异常区等作业队列 | 让不同岗位在正确功能区工作 | 参考事实＋建议设计 |
| `status` | 管理员启停 | 停用不能影响历史库存和任务查询 | 支持仓库改造和临时封闭 | 防止新任务进入不可用空间 | 建议设计 |

### 4.2 库位 `location`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `location_id` | 库位标识 | 统一 ID | BIGINT/UUID | 系统生成 |
| `location_code` | 库位编码 | 现场条码/编码 | VARCHAR | 必填 |
| `location_usage_type` | 库位使用方式 | 拣选、箱拣选、存储、预配、异常、过渡、工位、次品 | ENUM | 必填 |
| `storage_type` | 库位存储类型 | 普通/托盘 | ENUM | 必填 |
| `allow_mixed` | 是否允许货品混放 | `Y/N` | BOOLEAN | 按用途默认，待确认 |
| `capacity_volume` | 容积上限 | 数值＋单位 | DECIMAL | 可选 |
| `max_weight` | 承重上限 | 数值＋单位 | DECIMAL | 可选 |
| `used_volume` | 已用容积 | 数值＋单位 | DECIMAL | 系统计算 |
| `used_weight` | 已用承重 | 数值＋单位 | DECIMAL | 系统计算 |
| `pick_priority` | 拣货/路径优先级 | 正整数 | INT | 无优先级时待确认 |
| `storage_condition` | 存储条件 | 自定义值/不限 | VARCHAR/JSON | 默认不限或空 |
| `status` | 库位状态 | 启用/停用 | ENUM | 默认启用 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `location_usage_type` | 建档时配置 | 手册明确不同用途有不同锁定、上架和库存限制；不能只做展示枚举 | 可配置任务允许进入的库位用途 | 防止货物进入错误作业区 | 参考事实＋建议设计 |
| `allow_mixed` | 库位配置 | 手册明确过渡库位、异常暂存必须允许混放，其他场景需校验已有库存 | 可扩展混货主、混批次和混库存属性规则 | 防止串货和库位选择错误 | 参考事实＋建议设计 |
| `capacity_volume` / `max_weight` | 库位配置 | 自动补货、上架和移库会参考剩余容积和重量；单位和算法待确认 | 支持库容利用率和超容预警 | 避免上架后超容或超重 | 参考事实＋建议设计 |
| `used_volume` / `used_weight` | 库存/作业生效后计算 | 不允许人工随意覆盖，否则余额与库位容量不一致 | 支持库容看板和补货推荐 | 反映当前库位承载情况 | 参考事实＋建议设计 |
| `pick_priority` | 路径配置 | 手册出现 1—999999 优先级及排序逻辑；排序是否跨库区待确认 | 支持路径优化和任务分区 | 减少拣货、移库行走距离 | 参考事实＋建议设计 |
| `storage_condition` | 库位/商品配置 | 有库存或优先商品时，库位条件需与商品条件一致或为不限 | 支持温区、危化、冷链等扩展 | 避免商品进入不适宜位置 | 参考事实＋建议设计 |

### 4.3 容器与设备边界 `container` / `device_scope`

| 字段编码（建议） | 字段名称 | 字段格式/长度 | 数据类型/数据库属性 | 必填/默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `container_code` | 容器编码 | 条码/编码 | VARCHAR | 容器作业必填 |
| `container_type` | 容器类型 | 托盘、周转箱、拣货框等 | ENUM | 必填 |
| `container_status` | 容器状态 | 未使用、使用中、停用 | ENUM | 默认未使用 |
| `current_location_id` | 当前库位/工位 | 关联 ID | BIGINT/UUID | 使用中可选 |
| `device_code` | 设备编码 | 编码 | VARCHAR | 自动化场景必填 |
| `scope_rule` | 设备覆盖范围 | 库位/库区范围 | JSON/关联表 | 条件必填 |

| 字段编码 | 来源/生成时机 | 设计关注点 | 拓展用途 | 业务场景/解决问题 | 事实级别 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `container_code` | 容器建档或现场扫描 | 容器编码不能和库位或其他容器重复；使用中不能物理删除 | 支持按容器查询货物和作业轨迹 | 解决货物装箱后难以定位的问题 | 参考事实＋建议设计 |
| `container_status` | 绑定、释放或停用时更新 | 容器状态不能代替库存状态 | 支持周转效率和容器盘点 | 避免重复分配同一容器 | 建议设计 |
| `scope_rule` | 设备管理员配置 | 设备失败不能直接假定库存已移动 | 支持设备与人工任务切换 | 明确自动化作业边界 | 参考事实＋建议设计 |

## 5. 功能与首版取舍

| 优先级 | 功能 | 主要字段 | 取舍判断 |
| :--- | :--- | :--- | :--- |
| P0 | 仓库—区域—库区—库位 | 层级编码、状态 | 必须支撑精准定位和权限隔离 |
| P0 | 库位用途、类型和状态 | 使用方式、存储类型、状态 | 必须参与入库、出库和库存校验 |
| P0 | 库位优先级、容量和混放 | 优先级、容量、混放 | 先支持明确规则，不预设路径算法 |
| P1 | 容器基础档案与轨迹 | 容器编码、类型、当前位置 | 支撑箱拣选、装箱和现场追踪 |
| 后续 | 设备范围与设备任务 | 设备编码、覆盖范围 | 作为自动化仓库条件能力，暂不内置厂商协议 |
| 后续 | 三维库位和路径优化 | 坐标、路径权重 | 等现场编码和轨迹数据稳定后再做 |

## 6. 跨模块依赖、拓展与待确认

- 入库读取可收货/可上架库位；出库读取拣选和箱拣选库位；库存以库位作为精细库存维度；任务读取区域、库区、库位和资源边界。
- 可拓展到冷链温区、危化品隔离、自动化仓库、容器循环和库容分析。
- 库位库存是否允许同一 SKU 多批次并存、容量单位和计算方式、设备与人工任务切换条件，均待确认。
